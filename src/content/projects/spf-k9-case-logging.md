While serving as a narcotics detection dog handler and field training officer in the Singapore Police Force K-9 Unit, I designed, built and deployed a web application for the unit's case records.

## What it does

- Real-time digital case logging, so handlers record deployments as they happen instead of on paper
- Search and retrieval of past cases for the team
- Secure authentication, so only unit members can access records

## Stack

Vue.js on the front end, Firebase for authentication, data storage and hosting.
